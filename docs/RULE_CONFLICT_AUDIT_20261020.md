## 本次结论与 Git 证据

- 当前官方 GFWList 不含 douyin；额外合并的 Johnshall/cn-blocked-domain 包含 `www.douyin.com`。该项目 README 表明它爬取 Greatfire Analyzer 的屏蔽检测结果；未获得针对抖音的原始检测记录，因此不能认定曾真实被封或解释具体误判时刻。
- `factory/gfwlist.py` 将两个来源无差别合并，转换时忽略 `@@` 例外，丢失来源信息。
- 本仓库 `5ef59f1`（2024-02-04，Nightly build）加入 `www.douyin.com`；`1c4814c`（2024-08-26，Nightly build）移除。当前 build 分支保存的旧 resultant/gfw.list 不含该项，但当前额外上游和修复前实际客户端都包含。
- `99002a4`（2026-10-06）新增 PassWall 风格模板，将合并后的 GFW 列表放在中国直连列表之前。它没有手工指定抖音代理，但提供了冲突先命中代理的条件。
- 同类候选包括 `news.baidu.com`、`weixin.sogou.com`、`weather.com.cn`、`huaban.com`、`oschina.net`、`www.360.com`、`www.haodf.com`、`partner.toutiao.com`。它们是当前上游冲突候选，尚未逐个验证客户端实际命中及国内可达性。
- 富途、长桥等 5 条来源重叠记录命中个人代理设置，应保留。仅与 cn/top/wang 等顶级后缀重叠的 229 条也不能自动判断为误配。
- 不建议全局交换中国列表与 GFW 列表的顺序；中国列表包含整个顶级后缀，这样会让确实需要代理的站点直连。优先核验具体域名，再加入个人直连/排除项。
